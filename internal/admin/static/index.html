账号健康诊断

自动诊断只读取账号池、内存请求日志和官网额度接口，不发送聊天请求、不自动复活账号。额度接口成功不代表聊天链路正常；手动聊天测试会消耗积分。

账号 / 官网余额诊断与建议预计恢复最近成功近期尝试成功率参与重试的请求最近失败

近期指标仅覆盖本次启动后保留的日志。账号成功率按实际账号尝试计算（包括换号前的失败），与请求最终成功率不同；重试列按该账号参与过的重试请求去重计数。恢复时间为账号池冷却/熔断预计结束时间，不保证届时上游已恢复。

网关性能统计

仅覆盖本次启动后保留的最近 1000 条已结束请求，重启清空，与官网积分账单无关。耗时包括账号重试和响应传输；P95 表示 95% 的请求耗时不超过该值。首帧均值仅统计流式请求中有记录的首个数据帧。
